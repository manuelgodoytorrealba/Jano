# Foundational Editorial Policy v1

## Ficha

Use typed details only for stable, verifiable facts. Leave a field empty when a
work has no single current location, a detail is contested, or the field does
not apply. Do not put interpretation or graph relations in a ficha.

## Summary

Write one original Spanish summary, normally 80–180 words, then an editorial
English version with the same factual scope. It must identify the entity,
orient a first reading, and name the historical or cultural context that makes
it useful. It must not duplicate the ficha or enumerate graph edges.

## Essay

An essay needs a specific question that cannot be answered by ficha, summary,
or relations. It distinguishes fact from interpretation and attributes a
contested reading where necessary. Essays are optional and are never generated
merely because an entity is Tier A.

## Sources

Prefer collection, museum, archive, foundation, or heritage records for hard
facts. Use scholarly or curatorial references for definitions and
interpretation. One relevant source is better than a decorative bibliography.

## Import safety

Editorial imports fill only null fields. They never replace a translation,
essay, note, excerpt, source reference, or typed detail already present in the
database. Foundational reseeds own canonical identity only, never editorial
content.

# 10 — Glossary

| Término                       | Definición oficial                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------- |
| Research                      | Investigación privada que organiza corpus, conocimiento, argumento y escritura.                         |
| Biblioteca                    | Corpus documental: materiales, fuentes y extractos.                                                     |
| Material                      | Recurso incorporado: PDF, URL, imagen, mapa, libro o archivo.                                           |
| Fuente                        | Obra intelectual o bibliográfica representada por uno o más materiales.                                 |
| Extracto                      | Fragmento localizable de una fuente en una versión concreta.                                            |
| Evidencia                     | Uso argumentativo de una fuente o extracto respecto de un Claim.                                        |
| Claim                         | Afirmación atómica, revisable y evidenciable dentro de Research.                                        |
| Hipótesis                     | Estado de un Claim que requiere revisión; no objeto independiente.                                      |
| Hallazgo                      | Estado o etiqueta de un Claim suficientemente relevante; no objeto independiente.                       |
| Entidad privada               | Referente identificado dentro de un Research, sin identidad canónica automática.                        |
| Relación privada              | Claim estructurado entre entidades privadas.                                                            |
| Research Graph                | Proyección conectada de entidades y relaciones privadas.                                                |
| Pipeline Editorial            | Flujo funcional que prepara corpus y, mediante revisión humana, alimenta conocimiento privado trazable. |
| Editorial Job                 | Unidad observable y recuperable que prepara material o genera propuestas; nunca acepta conocimiento.    |
| Propuesta editorial           | Resultado revisable de procesamiento o IA que todavía no forma parte de Research Knowledge.             |
| Cola editorial                | Conjunto priorizado de decisiones humanas pendientes sobre documentos, Evidence y conocimiento privado. |
| Estado documental             | Disponibilidad editorial de un material, distinta del estado de un Job o de conocimiento revisado.      |
| Outline                       | Estructura argumental de Research.                                                                      |
| Sección                       | Unidad editorial de Outline.                                                                            |
| Contexto editorial / dossier  | Selección de referencias y notas para preparar una sección.                                             |
| Draft                         | Narrativa privada de trabajo de una Section, propiedad de Research.                                     |
| Draft Revision                | Versión inmutable del contenido y referencias editoriales de un Draft.                                  |
| Referencia editorial de Draft | Vínculo selectivo y trazable desde una Draft Revision a un Claim, Evidence o Extracto.                  |
| Research Review               | Decisiones sobre conocimiento y contenido privado.                                                      |
| Publication                   | Identidad duradera de una obra editorial derivada de Research.                                          |
| Publication Version           | Composición concreta y preservable de una Publication.                                                  |
| Editorial Edition             | Expresión editorial autónoma de una Publication Version.                                                |
| Promotion Proposal            | Propuesta explícita para una operación sobre el Knowledge Core.                                         |
| Knowledge Review              | Revisión humana de Promotion Proposals.                                                                 |
| Knowledge Core                | Entidades y relaciones canónicas compartidas por JANO.                                                  |
| Perspective                   | Proyección de una Publication o Edition; no posee datos propios.                                        |

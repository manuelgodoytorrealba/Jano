# JANO - Codex Project Instructions

## Project Overview
JANO is a premium web platform for art discovery, study, and connected knowledge.

It combines:
- visual exploration
- entity relationships
- collections
- intelligent recommendations
- admin curation tools

## Stack
- Frontend: Angular
- Backend: NestJS
- ORM: Prisma
- Database: PostgreSQL
- Dev: Linux / macOS hybrid workflow

## Code Principles
- Keep code clean, modular, and scalable
- Prefer reusable components
- Avoid unnecessary complexity
- Preserve existing working behavior unless requested
- Do not break current styles or UX flows

## UI Principles
- Premium aesthetic
- Clean spacing
- Elegant interactions
- Modern glass / refined interfaces where appropriate
- Strong visual hierarchy
- Responsive behavior

## Backend Principles
- Respect DTO patterns
- Keep services organized
- Maintain Prisma consistency
- Avoid risky schema changes unless requested

## Frontend Principles
- Prefer maintainable Angular patterns
- Keep templates readable
- Avoid bloated components
- Preserve responsiveness

## When Making Changes
- Explain what changed briefly
- Mention affected files
- Flag possible side effects
- Suggest next improvements when useful

## Priorities
1. Stability
2. UX quality
3. Clean architecture
4. Speed of iteration
